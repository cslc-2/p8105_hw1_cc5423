## Problem 1

Load the dataset:

``` r
data("penguins", package = "palmerpenguins")
```

### Data Description

The `penguins` dataset has information on the penguins’ species, island,
bill length (mm), bill depth (mm), flipper length(mm), body mass (g),
sex, and year. The dataset has 344 observations and 8 variables. The
mean flipper length is 200.92 mm.

### Scatterplot

``` r
ggplot(penguins, aes(x = bill_length_mm, y = flipper_length_mm, color = species)) + geom_point()
```
